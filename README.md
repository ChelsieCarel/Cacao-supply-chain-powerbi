Dashboard Power BI développé dans le cadre d'un **challenge compétitif** analysant la filière cacao ivoirienne — de la ferme au port d'exportation.
**151 800 mouvements** analysés sur la période 2022–2025.

### Pages du Dashboard
| Page | Description |
|------|-------------|
| 🏠 Vue Générale | KPIs globaux, CA Net, Marge, Variations YOY |
| 🌱 Production | Récolte, fermes, coopératives, certifications |
| 🔬 Qualité & Logistique | Humidité, pertes, transport, ports |
| ⚓ Export & Finance | CA Net, primes, projections 5 ans |

### Insights Clés
- ⏱️ Délai de **3 mois** entre pic transport (octobre) et export (janvier)
- ⚠️ Le **Trinitario** présente le taux de perte le plus élevé
- ⚓ **San-Pédro** domine les exportations en volume et valeur
- 🌿 Coopératives **non certifiées** dominent en volume mais perdent en valeur
- 💧 Humidité moyenne **7,49%** — sous le seuil critique de 8% ✅
